This project delivers a Stylistic Text Generator Comparator, a valuable tool for sports journalists. It allows for a direct comparison between text generated by a LoRA-adapted Language Model and an N-gram model, both fine-tuned on unique sports commentary styles. The training data used in this project is a bundled sports commentary corpus included directly in the repository.

## What you are building

**Goal.** A command-line tool for sports journalists to compare text generated by a LoRA-adapted LLM with an N-gram model, both fine-tuned on specific sports commentary styles.

**Done when.** The project is complete when you have successfully fine-tuned a pre-trained LLM with LoRA on a custom sports commentary style and can compare its text generation quality against an n-gram model built from the same text corpus.

## Run it

You need Python 3.10+ and git.

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python -m app.cli hello
pytest
```

### CLI Commands

```bash
# Check setup
python -m app.cli hello

# Side-by-side comparison (main feature)
python -m app.cli compare --prompt "Rashford bursts down the wing" --epochs 2

# Train and save LoRA weights for later reuse
python -m app.cli train-lora --save-path weights/lora.pt --epochs 3

# Load cached weights instead of retraining
python -m app.cli compare --prompt "Goal!" --load-lora weights/lora.pt
```

## Evaluation & Limitations
**Baseline Comparison:** 
The 3-gram model serves as our simple baseline. It is extremely fast and lightweight to train but struggles with long-range coherence, often repeating phrases or losing context after a few words. 

**LoRA-Adapted LLM:** 
The LoRA-adapted model (based on distilgpt2) performs significantly better at maintaining stylistic coherence and grammar. However, it falls short in terms of computational efficiency. It requires much more memory and time to train, even with low-rank adaptation, and can occasionally hallucinate facts not present in the training data.

**Data Source:**
The training data used is a bundled sports commentary corpus (approx. 300 words) included directly in this repository.
