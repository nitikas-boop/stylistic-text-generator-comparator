# Stylistic Text Generator Comparator

[![Built with askThili](https://msrit.ask.thili.ai/api/v1/public/projects/dwcurj7rzn/badge.svg)](https://msrit.ask.thili.ai/b/dwcurj7rzn)
[![Built with askThili](https://ask.thili.ai/api/v1/public/projects/dwcurj7rzn/badge.svg)](https://ask.thili.ai/b/dwcurj7rzn)

This project delivers a Stylistic Text Generator Comparator, a valuable tool for sports journalists. It allows for a direct comparison between text generated by a LoRA-adapted Language Model and an N-gram model, both fine-tuned on unique sports commentary styles. You will demonstrate your ability to fine-tune advanced models and build traditional NLP models for stylistic text generation and comparison.

## What you are building

**Goal.** You will build a tool for sports journalists to compare text generated by a LoRA-adapted LLM with an N-gram model, both fine-tuned on specific sports commentary styles.

**Done when.** The project is complete when you have successfully fine-tuned a pre-trained LLM with LoRA on a custom sports commentary style and can compare its text generation quality against an n-gram model built from the same text corpus.

## Milestones

Tick these off as you go, and commit after each one.

- [ ] **1. Prepare a small corpus of sports commentary text.**  
      Hint: Gather and preprocess your text data.
- [ ] **2. Implement the n-gram model and generate text from it.**  
      Hint: Apply the "Build a Next-Word Predictor from Scratch" drill's technique to build your n-gram model.
- [ ] **3. Load a small pre-trained LLM and implement LoRA adapter injection.**  
      Hint: Use the "Build LoRA from Scratch" drill's technique to inject the LoRA adapter into a pre-trained LLM.
- [ ] **4. Fine-tune the LoRA adapter on the sports commentary corpus.**  
      Hint: Train the LoRA adapter on your corpus, as shown in the "Build LoRA from Scratch" drill.
- [ ] **5. Generate text from the LoRA-adapted LLM.**  
      Hint: Use your fine-tuned LoRA model to generate text.
- [ ] **6. Provide a qualitative comparison interface for generated texts from both models.**  
      Hint: Design an interface to visually compare the outputs of both models.

## Run it

You need Python 3.12 and git.

```bash
python3.12 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env        # then choose a model; see the comments inside
python -m app.cli hello
pytest
```

Your work goes in `app/core.py` (one stub per milestone) and `tests/test_core.py`. The first tests pass already; they
check the plumbing.

## Settings and secrets

Model settings live in `.env`, which is ignored by git. **Never commit `.env` or paste a key into code.** If a key ever
reaches GitHub, treat it as leaked and make a new one.
