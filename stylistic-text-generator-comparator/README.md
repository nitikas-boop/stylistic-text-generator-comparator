# Stylistic Text Generator Comparator

[![Built with askThili](https://msrit.ask.thili.ai/api/v1/public/projects/dwcurj7rzn/badge.svg)](https://msrit.ask.thili.ai/b/dwcurj7rzn)
[![Built with askThili](https://ask.thili.ai/api/v1/public/projects/dwcurj7rzn/badge.svg)](https://ask.thili.ai/b/dwcurj7rzn)

This project delivers a Stylistic Text Generator Comparator, a valuable tool for sports journalists. It allows for a direct comparison between text generated by a LoRA-adapted Language Model and an N-gram model, both fine-tuned on unique sports commentary styles. The training data used in this project is a bundled sports commentary corpus included directly in the repository. You will demonstrate your ability to fine-tune advanced models and build traditional NLP models for stylistic text generation and comparison.

## What you are building

**Goal.** You will build a tool for sports journalists to compare text generated by a LoRA-adapted LLM with an N-gram model, both fine-tuned on specific sports commentary styles.

**Done when.** The project is complete when you have successfully fine-tuned a pre-trained LLM with LoRA on a custom sports commentary style and can compare its text generation quality against an n-gram model built from the same text corpus.

## Run it

You need Python 3.12 and git.

```bash
python3.12 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env        # then choose a model; see the comments inside
python -m app.cli hello
pytest
```

Your work goes in `app/core.py` and `tests/test_core.py`. The first tests pass already; they check the plumbing.

## Settings and secrets

Model settings live in `.env`, which is ignored by git. **Never commit `.env` or paste a key into code.** If a key ever reaches GitHub, treat it as leaked and make a new one.

## Stretch ideas

- Adapt the models to generate text in multiple distinct sports commentary styles by using different corpora for fine-tuning.
